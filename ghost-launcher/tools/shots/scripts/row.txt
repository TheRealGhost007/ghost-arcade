#! env SHOTS_ADMIN=0 SHOTS_EXTRA_GAMES=1
# Phase 4, your row: F and the card's Favourite put a gold star on a machine
# and bring it first; T steps the row order (your order, recently played,
# most played, A-Z); each order is a view only, kept in launcher.ini, and
# Enter, an install and Shift+U still act on the machine the hall shows lit.
# A wrap jumps instead of sliding past the row. Chipforge is a tool.
# Extra 1 is the last line of games.txt but stands mid-row in A-Z, so the
# A-Z steps below act on machines whose place is not their catalog line.
wait 30
expect app order Your order

# only marks itself done, and games.txt is left as it was.
expect file .config/ghost-launcher/launcher.ini migrated.retired=1\n
expect file .config/ghost-launcher/games.txt catalog for the screenshot harness

tap RIGHT

expect app lit Brickburst
expect app place 0
expect app settled 1
expect app status Brickburst is a favourite now: favourites come first.
