# Phase 6: attract mode's other rules. Pad A wakes it and plays nothing; an
# F11 that wakes it does not switch fullscreen; with Reduced flashing the
# prompt holds steady; it never starts while a game the launcher started is
# running (the quiet hall wins) or under the Arcade menu; Settings > Screen
# turns it off or makes it wait two minutes (launcher.ini attract_mode).
wait 30
pad on
wait 3600
expect app attract 1
pad tap A
wait 2
expect app attract 0
wait 80
expect launches 0

# F11 wakes it and does nothing else.
wait 3600
expect app attract 1
tap F11
wait 3
expect app attract 0
expect fullscreen 0
expect prefs fullscreen 0

# Reduced flashing: PRESS ANY BUTTON holds steady.
write .config/ghost-arcade/prefs.ini music_volume=70\nscreen_shake=1\nreduced_flashing=1\nfullscreen=0\n
focus off
wait 2
focus on
wait 2
expect prefs reduced_flashing 1
wait 3600
expect app attract 1
wait 70

shot attract-steady

wait 3
expect app attract 0
wait 80
expect launches 0
