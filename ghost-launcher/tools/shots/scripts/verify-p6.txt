# Phase 6 verification: what the extras' first build got wrong.
# - A wheel flick is one gesture: its first notch wakes attract mode, and
#   the notches right behind it must not move the row off your machine
#   (they moved it two machines on). A notch after the settle moves it.
# - Shift alone is a key: it wakes attract mode (and does nothing else).
# - A double-click on a page's Daily challenge: the first click opens the
#   desk, the second landed on a desk row and played that machine's daily
#   (Moondrop's, on Skyraid's page). The desk now ignores the left button
#   for a moment after a click opened it, as the page does.
# - Shift+D on a page opens the desk, as on the hall (it did nothing, and
#   before the desk it was the page's Daily).
# - Settings > Screen > Attract mode: each choice's note stays in its row.
# Every machine is installed here (SHOTS_UNINSTALLED is empty), so the row
# the double-click's second click lands on (Moondrop's) is one that plays;
# Extra 1 is a machine with no daily challenge.
